# QM & QC 学习笔记

这是一个公开的中文学习笔记仓库，用于系统整理 Quantum Mechanics（量子力学，QM）与 Quantum Computing（量子计算，QC）的概念、推导、习题解答和来源记录。

量子力学部分以 R. Shankar 的 *Principles of Quantum Mechanics* 为主要资料；量子计算部分将在确定主要资料后按照相同规范维护。本仓库不是教材翻译、官方讲义或标准答案，不能替代原始教材及正式课程资料。

## 内容面向谁

本仓库面向具备微积分、基础线性代数和初等经典力学知识，并正在系统学习量子力学或量子计算的本科生及自学者。内容以可追踪、可复核的学习记录为目标，不以简化教材或提供速成材料为目的。

笔记强调：

- 明确数学对象、标量域、假设和符号；
- 补全自己需要的推导步骤；
- 区分教材内容、对话补充和自拟检查题；
- 保存教材章节与页码，方便回到原始来源核对；
- 记录错误、订正和仍未解决的问题，而不是把不确定内容写成结论。

## 仓库结构

```text
.
├── main.tex                   # PDF 编译入口
├── study-map.tex              # PDF 内的学习地图
├── chapters/                  # 教材精讲笔记
├── exercises/                 # 教材习题、订正与自拟检查题
├── figures/                   # 原创或明确许可的图片
├── latex/
│   ├── preamble.tex           # 共享版式、元数据和交叉引用命令
│   └── macros.tex             # 常用数学与量子力学记号
├── templates/                 # 新学习单元和习题文件模板
├── learning-log.md            # 按日期记录学习进度
├── AGENTS.md                  # 内容维护与公开发布规范
├── Makefile                   # 本地编译命令
└── .gitignore                 # 忽略教材、PDF 和编译产物
```

正文与习题分开保存。完整题目和完整解答进入 `exercises/`；正文只保留定义、推导、微型例子、常见误区和到相关练习的交叉引用。

## 编译 PDF

推荐使用安装了 XeLaTeX 与 `latexmk` 的 TeX Live 或 MacTeX。仓库使用 `ctex` 排版中文。

```bash
make pdf
```

生成结果位于：

```text
build/main.pdf
```

清理编译产物：

```bash
make clean
```

编译成功只说明 LaTeX 语法和依赖通过，不能证明物理内容正确。内容更新后还需要检查公式、页码、交叉引用和 PDF 版式。

## 来源与版权边界

本仓库不包含且不得提交教材 PDF、扫描页、教材截图、课程平台材料、答案册或大段教材原文。教材文件保存在仓库之外；`.gitignore` 同时排除所有 PDF 和约定的本地资料目录。教材习题只保留完成解答所需的题意概述，笔记以总结、推导和个人理解为主。

书名、章节号和页码仅用于来源定位。教材本身的版权归原作者与出版社所有。仓库中的解答和解释可能存在错误，引用前请回到原始资料复核。
