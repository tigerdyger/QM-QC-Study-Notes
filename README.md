# QM & QC 学习笔记

这是一个公开的中文学习笔记仓库，用于长期整理 Quantum Mechanics（量子力学，QM）与 Quantum Computing（量子计算，QC）的概念、推导、习题和学习进度。

当前实际内容是对 R. Shankar 的 *Principles of Quantum Mechanics* 进行逐节精读；量子计算部分尚未开始。仓库记录的是个人学习过程，不是教材翻译、官方讲义或标准答案，也不能替代原教材。

## 当前进度

- 当前主线：Shankar, *Principles of Quantum Mechanics*
- 已完成：第 1 章第 1.1 节 `Linear Vector Spaces: Basics`
- 完成内容：分块讲解、教材练习 1.1.1--1.1.5、订正、收口检查与 LaTeX 笔记
- 详细记录：[learning-log.md](learning-log.md)

按教材目录统计，全书共有 21 章、约 99 个正文学习单元；第 6 章没有编号小节，在计划中按一个单元计算。当前完成 1 个单元，还剩约 98 个。若每天完成一个单元且不中断，预计还需 98 天，约 3.2 个月；若每周学习 5--6 天并保留复习时间，更现实的周期约为 4--5 个月。

这里的“一个单元”按教材编号小节计算，不保证工作量相同。长小节、推导密集章节和习题较多的部分可能拆成多天。

## 内容面向谁

仓库主要面向正在学习量子力学或准备进入量子计算的本科生和自学者。读者最好具备微积分、基础线性代数和初等经典力学知识。

笔记强调：

- 明确数学对象、标量域、假设和符号；
- 补全自己需要的推导步骤；
- 区分教材内容、对话补充和自拟检查题；
- 保存教材章节与页码，方便回到原始来源核对；
- 记录错误、订正和仍未解决的问题，而不是把不确定内容写成结论。

## 仓库结构

```text
.
├── main.tex                   # PDF 编译入口
├── study-map.tex              # PDF 内的学习地图
├── chapters/                  # 教材精讲笔记
├── exercises/                 # 教材习题、订正与自拟检查题
├── figures/                   # 原创或明确许可的图片
├── latex/
│   ├── preamble.tex           # 共享版式、元数据和交叉引用命令
│   └── macros.tex             # 常用数学与量子力学记号
├── templates/                 # 新学习单元和习题文件模板
├── learning-log.md            # 按日期记录学习进度
├── AGENTS.md                  # 内容维护与公开发布规范
├── Makefile                   # 本地编译命令
└── .gitignore                 # 忽略教材、PDF 和编译产物
```

正文与习题分开保存。完整题目和完整解答进入 `exercises/`；正文只保留定义、推导、微型例子、常见误区和到相关练习的交叉引用。

## 编译 PDF

推荐使用安装了 XeLaTeX 与 `latexmk` 的 TeX Live 或 MacTeX。仓库使用 `ctex` 排版中文。

```bash
make pdf
```

生成结果位于：

```text
build/main.pdf
```

清理编译产物：

```bash
make clean
```

编译成功只说明 LaTeX 语法和依赖通过，不能证明物理内容正确。内容更新后还需要检查公式、页码、交叉引用和 PDF 版式。
